# Changelog

## 0.2.1-rc.2 (2026-10-30)

Initial DeepSeek Harness (DSH) native skill port. The upstream workflow and supporting references/templates are preserved from upstream skill version 1.0.1. DSH-specific compatibility metadata, beginner installation/use guidance, and a porting report are added. This port version identifies the target harness compatibility baseline and does not claim to be a new upstream method release.

# Changelog

## 1.0.1 (2026-10-26)

Wording and attribution only, no change to the method. The README and SKILL.md credit REA (Reverse Engineer Anything) by @morluto (github.com/morluto/rea) as the inspiration, with the note that this skill is independent and not affiliated; the one-liner now ends "until every must-have on a written checklist passes" where it said "100% there"; the README gains a Quick start; the run-ledger template is linked where the ledger is first appended to. ## 1.0.0 (2026-10-23)

First release. The completion loop (define 100% before building, build a walking skeleton, review against the original with evidence, plan, improve, repeat until every must-have passes in two consecutive reviews) with a parity checklist per product class, a fresh-eyes review pass, regression sampling, stop conditions and a hand-over set; the examination method condensed from Reverse Engineer Anything v1.14 (safe handling, preflight, identification, routes, inventory passes, ledger, live rules); the self-learning loop adapted from Hermes Agent as a Skill File v2.1 (what is learned and where, the review prompt, the shape of a lesson, never capture, staged approval, ledger, recall); fix recipes by cause; four templates.
